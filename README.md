# AI & Machine Learning Project Portfolio

This repository contains a curated collection of **Artificial Intelligence (AI)** and **Machine Learning (ML)** projects developed through academic coursework, self-driven learning, and hands-on experimentation.  
Each project focuses on applying core AI/ML concepts to real-world datasets and problem domains.

The goal of this portfolio is to demonstrate practical skills in **model development**, **data analysis**, **system integration**, and **applied AI workflows**.

---

##  Projects Overview

### 🔹 AWS DeepRacer
**Domain:** Reinforcement Learning, Cloud-Based AI  
**Key Skills:** AWS DeepRacer, reward function design, experimentation, optimization

**Description:**  
This project explores reinforcement learning using AWS DeepRacer. It includes multiple reward function experiments, training iterations, and a finalized optimized model. Supporting documentation and notes explain the learning process and tuning decisions.

**Highlights:**
- Custom reward functions
- Training and evaluation experiments
- Final optimized racing policy
- Usage notes and manual

Folder: `AWS DEEPRACER/`

---

### 🔹 Cardiovascular Disease Prediction
**Domain:** Supervised Machine Learning, Healthcare Analytics  
**Key Skills:** Data preprocessing, model comparison, performance evaluation

**Description:**  
A machine learning project focused on predicting cardiovascular disease using structured health data. Multiple classification models are trained and compared to evaluate predictive performance.

**Highlights:**
- Logistic Regression, K-Nearest Neighbors (KNN), Random Forest, Gradient Boosting
- Evaluation using accuracy, precision, recall, and confusion matrices
- Backend integration for prediction via API

 Folder: `Cardiovascular Disease/`

---

### 🔹 Diabetes Prediction
**Domain:** Classification, Exploratory Data Analysis  
**Key Skills:** Feature engineering, modeling, notebook-based analysis

**Description:**  
This project builds a complete ML workflow for diabetes prediction, from data exploration and preprocessing to model training and evaluation using Jupyter notebooks.

**Highlights:**
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and evaluation
- End-to-end notebook workflow

 Folder: `Diabetes Prediction/`

---

### 🔹 Anime Rating Prediction
**Domain:** Regression, Predictive Modeling  
**Key Skills:** Data cleaning, regression modeling, dataset analysis

**Description:**  
A predictive modeling project aimed at estimating anime ratings based on structured dataset features. Emphasis is placed on data preprocessing and model accuracy.

**Highlights:**
- Dataset preprocessing
- Regression-based prediction
- Feature impact analysis

 Folder: `Rating-Prediction-file/`
